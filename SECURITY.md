## 🚨 Reporting a Vulnerability

The PhishGuard AI team takes the security of our threat detection engine and APIs very seriously.

If you believe you have found a security vulnerability in PhishGuard AI:

1. **Do not disclose the vulnerability publicly** on GitHub issues, social media, or discussion forums.
2. Please submit a private vulnerability report via GitHub Security Advisories or contact the maintainers.
3. Include the following details:
   - Type of vulnerability (e.g. Remote Code Execution, Denial of Service, Path Traversal, Logic Bypass).
   - Step-by-step instructions or Proof of Concept (PoC) to reproduce the behavior.
   - Potential impact and affected endpoints/modules.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure and patch release.
