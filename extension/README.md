# 🛡️ PhishGuard AI — Brauzer Kengaytmasi (Chrome & Edge)

Ushbu kengaytma internetda veb-sahifalarni real vaqt rejimida foniy tekshirib, foydalanuvchini soxta fishing saytlari, bank kartasi ma'lumotlarini o'g'irlovchi soxta havolalar va firibgarlikdan himoya qiladi.

---

## 🚀 Brauzerga o'rnatish qo'llanmasi (1 daqiqada):

1. **Google Chrome** yoki **Microsoft Edge** brauzerini oching.
2. Manzil qatoriga quyidagini yozib **Enter** bosing:
   * Google Chrome uchun: `chrome://extensions/`
   * Microsoft Edge uchun: `edge://extensions/`
3. O'ng yuqori burchakdagi **"Dasturchi rejimi" (Developer mode)** kalitini yoqing.
4. Chap yuqori burchakda paydo bo'lgan **"Yuklangan kengaytmani yuklash" (Load unpacked)** tugmasini bosing.
5. Loyiha ichidagi ushbu `extension` papkasini tanlang.
6. **Tayyor!** Brauzeringizning yuqori panelida **PhishGuard Shield** qalqon belgisi paydo bo'ladi.

---

## 🎯 Sinovdan o'tkazish (Demo):

1. **PhishGuard backend serveri** ishlab turganiga ishonch hosil qiling (`http://127.0.0.1:8000`).
2. Brauzerda xavfli fishing havolasini ochishga urinib ko'ring (masalan: `http://payme-security.com/login`).
3. **Natija:** PhishGuard Shield sahifani ochilishiga yo'l qo'ymasdan, darhol to'xtatadi va qizil xavfsizlik ogohlantirish ekranini (`blocked.html`) ko'rsatadi!
4. Qalqon belgisini bosganingizda esa ochilgan sahifaning real vaqt xavf darajasi ko'rinadi.
